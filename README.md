# OpenSIM — Sistema Integral Modular (FOSS)

FOSS rewrite of TecNM Morelia's academic management system.

- **Stack:** SvelteKit `3.0.0` + Svelte `5.57.1` (Runes) + Cloudflare D1 + Drizzle ORM `0.45.3`
- **Plan:** ISIC-2010-224 (Ingeniería en Sistemas Computacionales)
- **UI language:** Spanish (es-MX)
- **Code language:** English
- **A11y target:** WCAG 2.1 AA

## Quick start

```bash
pnpm install
pnpm run dev
```

## Scripts

| Script | What it does |
| --- | --- |
| `pnpm dev` | Vite dev server |
| `pnpm build` | Wrangler types check + Vite production build for Cloudflare |
| `pnpm preview` | Wrangler dev against the built Worker |
| `pnpm check` | svelte-kit sync + svelte-check + wrangler types |
| `pnpm test:unit` | Vitest (unit tests) |
| `pnpm db:generate` | Drizzle Kit — generate SQL migrations |
| `pnpm db:migrate` | Drizzle Kit — apply migrations to D1 |
| `pnpm db:studio` | Drizzle Kit — local SQLite studio |
| `pnpm db:seed` | Seed curriculum dataset into local D1 |

## Project layout

```
src/
  app.html
  app.d.ts
  lib/
    components/ui/        # 18 atomic Svelte 5 components

    +page.svelte

  tasks/opensim.md        # Canonical spec
docs/

```

## D1

Local D1 runs via Miniflare. Migrations in `./drizzle/` are generated by Drizzle Kit and applied by Wrangler. The seed script (`pnpm db:seed`) is idempotent and inserts the ISIC-2010-224 curriculum (42 subjects, 2 specialties).

## Conventions

- English: code, components, props, types, comments, commits
- Spanish: UI copy (button labels, error messages)
- Conventional Commits on `feat/phase-1-foundation` (current branch)
- No Tailwind, no Lenis, no Motion.dev — pure Svelte 5 + CSS tokens
- WCAG 2.1 AA contrast on text
